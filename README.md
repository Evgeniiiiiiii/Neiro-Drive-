# Neiro-Drive-
Веб-приложение для организации работы команды: ведения деловых контактов, распределения задач и планирования событий.
Контакты, задачи и мероприятия объединены в одном интерфейсе. Сотрудники могут назначать задачи коллегам, приглашать участников на события и получать внутренние уведомления.
Основные возможности:
Регистрация, вход и роли администратора и сотрудника.
База контактов с поиском и фильтрацией.
Задачи с исполнителями, приоритетами, сроками и статусами.
Календарное и списочное представление событий.
Уведомления о назначениях и изменениях.
Сводная панель с активными и просроченными задачами, ближайшими событиями.
Общий поиск по контактам, задачам и событиям.
Демонстрация:
В проекте предусмотрены тестовые пользователи и демонстрационные данные. Они позволяют познакомиться с интерфейсом и пройти основные сценарии работы команды.
Интерфейс выполнен на русском языке. Для развёртывания предусмотрен Docker Compose.****
